# 状态机情景验证工作台

在浏览器里定义状态机（状态 / 事件 / 守卫 / 动作）并编排情景（并发事件、取消信号），
服务端以**确定性虚拟时钟**执行仿真，把每一步状态变化流式推回页面。
本工具只验证抽象状态机，不控制任何真实系统。

## 快速开始

```bash
npm install
npm run dev        # 同时启动服务端(:3001)与 Vite 客户端(:5173)
```

打开 http://localhost:5173 ，点击「创建会话」→「运行」。

```bash
npm test           # 引擎与会话语义单元测试（13 个用例）
npm run smoke      # 端到端冒烟（需先 npm run dev:server）
npm run typecheck
```

## 执行语义（服务端保证）

| 语义 | 实现 |
| --- | --- |
| 同刻竞争决胜 | 事件按 `(虚拟时刻, priority, 序列号)` 全序排列，顺序明确可复现 |
| 嵌套派发 | 动作 `raise` 的事件进入 deferred 区，当前批次清空后才并入队列，**绝不插到当前批次之前** |
| 取消与完成竞争 | 取消信号 `$cancel` 本身也是有序事件，与目标事件的先后由同一全序决定 |
| 失败处理 | 守卫/动作抛错 → 结构化错误（`GUARD_ERROR`/`ACTION_ERROR`）；`onError: "rollback"` 回滚当前转移（状态、上下文、派生事件全部还原）后继续，`"abort"` 终止情景 |
| 暂停/继续/单步 | 执行泵以事件为边界启停，只改变节奏，不改变执行顺序 |
| 断线重连 | 客户端持久化 `lastAck`，重连后服务端只补发 `seq > lastAck` 的条目；客户端再按 seq 去重，绝不重复应用 |
| 有界缓冲 | 会话事件日志上限 500 条；续传发现缺口时先发 `resync` + 全量快照 |
| 会话过期 | 无连接且闲置超 TTL（默认 15 分钟，`SESSION_TTL_MS` 可配）的会话被清扫；重连得到 `SESSION_EXPIRED` |

## 结构

```
shared/types.ts      前后端共享的协议与模型类型
server/engine.ts     确定性虚拟时钟引擎（批次、deferred、回滚）
server/registry.ts   可注入的守卫/动作注册表（引擎只按名字引用）
server/session.ts    会话：有界缓冲、节奏控制、续传、过期
server/index.ts      Express(REST) + ws(/ws) 入口
client/src/App.tsx   工作台界面：编辑器 / 控制 / 状态 / 队列 / 单步差异
server/engine.test.ts  同刻竞争、嵌套派发、取消竞争、回滚、重连、过期用例
scripts/smoke.ts     端到端冒烟脚本
```

## 界面说明

- **状态机定义 / 情景编排**：JSON 编辑，`onError` 切换 `rollback`/`abort` 可直接对比行为差异。
- **执行控制**：运行 / 暂停 / 继续 / 单步 / 步进×10；「模拟断线重连」演示续传；可注入外部事件。
- **当前状态**：虚拟时钟、当前状态、上下文。
- **事件队列**：按决胜顺序展示待处理事件（时刻、优先级、token、来源）。
- **步骤日志**：每步的转移、守卫结果、上下文差异（删除线=旧值，绿色=新值）、派生事件、取消事件、结构化错误。

默认示例覆盖全部特性：`PAUSE`/`RESUME` 在 t=7 同刻竞争，`raiseTick` 嵌套派生自驱动链路，
`RISKY` 在 t=12 触发动作失败回滚，t=20 的取消信号与派生的 `TICK` 竞争。
